# Magic Animals & Friends

A browser game designed by Dahlia. Walk through four magic worlds, talk to animals,
become them, and finish every challenge across five levels.

**Play:** open `index.html` in a browser, or visit the GitHub Pages link for this repository.

- Arrow keys (or W A S D) to move, Space for magic. On an iPad, use the on-screen buttons.
- Plain HTML, CSS and JavaScript. No build step.

## Where things are

| File | What it is |
|---|---|
| `index.html`, `style.css` | The page, title screen and touch buttons |
| `game.js` | The game: moving, talking, transforming, levels, saving |
| `challenges.js` | Every challenge and the fog puzzles |
| `data/scenes.js` | The four worlds |
| `data/animals.js` | The animals |
| `data/levels.js` | The five levels: where animals live, challenges, clues, gems, doors |
| `sounds.js`, `music.js` | Sound effects and background music (made with code) |
| `assets/` | All the art (SVG) |
